Appendix D

反向传播：手算一遍

一个 9 个参数的小网络，每个数字都写出来

约 2 小时 第 4 章读不懂就看这里 需要纸和笔

第 4 章讲的是同一件事，但用了矩阵符号，从两层直接推到十层。 这一节反过来做：把网络缩到最小，小到每个数字都能手算， 一步一步走完前向、反向、更新，再回头看那些公式，你会发现它们只是这一遍的简写。

怎么读这一节

拿一张纸。每读到一处计算，先自己算一遍，再往下看结果。 光看不算，读完还是云里雾里。这一节的所有数字都是实际算出来的，你可以逐个核对。

D.1 先把网络缩到最小

第 4 章的网络是「任意宽度、任意层数」。但理解反向传播不需要那么复杂。

我们用一个 2 → 2 → 1 的网络：两个输入，两个隐藏神经元，一个输出。

输入 x = [x₁, x₂]
↓ 第一层：z = W₁x + b₁，然后 h = ReLU(z)
隐藏 h = [h₁, h₂]
↓ 第二层：ŷ = W₂h + b₂
输出 ŷ（一个数）
↓ 损失 L = ½(ŷ − y)²

全部参数一共 9 个：

表 D-1　这个网络的全部参数
参数形状取值作用
W₁(2, 2)[[0.1, 0.2], [0.3, 0.4]]输入 → 隐藏
b₁(2,)[0, 0]第一层偏置
W₂(2, 1)[[0.5], [0.6]]隐藏 → 输出
b₂(1,)[0]第二层偏置

输入和目标也定死：

x = [1, 2]　　y = 1　　（学习率 η = 0.1）

为什么偏置全设成 0？因为这样算式最短，能看清结构。真实训练里偏置也是随机初始化的，但梯度公式完全一样。

D.2 前向：从输入算到损失

前向就是「按顺序把每层的算式代进去」。四步。

第 1 步：第一层的线性部分

z = W1x + b1

展开成标量，每个分量单独算：

z₁ = 0.1 × 1 + 0.2 × 2 = 0.5
z₂ = 0.3 × 1 + 0.4 × 2 = 1.1

所以 z = [0.5, 1.1]。

第 2 步：过 ReLU

h = ReLU(z) = [max(0, z₁), max(0, z₂)]

两个都是正数，所以原样通过：

h = [0.5, 1.1]

第 3 步：第二层

ŷ = W2h + b2 = 0.5 × 0.5 + 0.6 × 1.1
ŷ = 0.25 + 0.66 = 0.91

第 4 步：损失

L = ½(ŷ − y)² = ½(0.91 − 1)² = ½ × 0.0081 = 0.00405
要点

前向没有任何新东西：一次矩阵乘、一次 ReLU、一次矩阵乘、一个平方。 难的部分全在反向。所以先把这四步在纸上走一遍，确认数字对得上，再往下。

D.3 反向：从损失往回走

反向传播要回答的问题是：L 对每个参数的偏导是多少？

一共有 9 个参数要算：W₁ 四个、b₁ 两个、W₂ 两个、b₂ 一个。

但我们不从参数开始，从损失开始往回走。这是整个方法的核心。

第 1 步：L 对 ŷ 的导数

L = ½(ŷ − y)²　⟹　∂L/∂ŷ = (ŷ − y)

代入数字：

∂L/∂ŷ = 0.91 − 1 = −0.09

这个数的含义很直白：ŷ 每增加一点，L 就变化 −0.09 倍。 因为 ŷ = 0.91 比目标 1 小，所以要让它变大——而梯度是负的，正好指示「往正方向调」。

第 2 步：ŷ 由谁决定

ŷ = W₂₀ · h₀ + W₂₁ · h₁ + b₂

（用 W₂₀ 表示 W₂ 的第 0 个元素，下同。这里 b₂ = 0，先忽略。）

从这个式子能直接读出两件事：

  • ŷ 对 W₂₀ 的偏导 = h₀（因为 W₂₀ 的系数就是 h₀）
  • ŷ 对 h₀ 的偏导 = W₂₀（因为 h₀ 的系数就是 W₂₀）

这就是链式法则的全部内容：谁和谁相乘，导数就是对方。

第 3 步：L 对 W₂ 的梯度

用链式法则把两步串起来：

∂L/∂W₂₀ = ∂L/∂ŷ × ∂ŷ/∂W₂₀ = (−0.09) × h₀ = −0.09 × 0.5 = −0.045
∂L/∂W₂₁ = ∂L/∂ŷ × ∂ŷ/∂W₂₁ = (−0.09) × h₁ = −0.09 × 1.1 = −0.099

写成向量就是：

∂L/∂W2 = ∂L/∂ŷ · h = −0.09 × [0.5, 1.1] = [−0.045, −0.099]
记住这个模式

权重的梯度 = 上游传来的梯度 × 这个权重的输入。

W₂ 的输入是 h（隐藏层的输出），所以乘 h。等一下算 W₁ 时，它的输入是 x，就乘 x。 同一个模式，只是换了名字。

第 4 步：L 对 h 的梯度

反向传播必须继续往回流，因为 h 也是「算出来的」，它背后还有 W₁。

∂L/∂h₀ = ∂L/∂ŷ × ∂ŷ/∂h₀ = (−0.09) × W₂₀ = −0.09 × 0.5 = −0.045
∂L/∂h₁ = ∂L/∂ŷ × ∂ŷ/∂h₁ = (−0.09) × W₂₁ = −0.09 × 0.6 = −0.054
∂L/∂h = [−0.045, −0.054]
对照

注意第 3 步用的是 h，这一步用的是 W2。 算权重的梯度时乘「输入」，算输入的梯度时乘「权重」。两者刚好交换。

第 5 步：穿过 ReLU

h = ReLU(z)，所以要先问：ReLU 的导数是什么？

ReLU′(z) = 1（z > 0）　　0（z ≤ 0）

直觉上：正数区是恒等映射，斜率 1；负数区被压成 0，斜率 0。 所以 ReLU 的导数就是一个「开关」——正数放行，负数截断。

这里的 z = [0.5, 1.1]，两个都大于 0，所以全部放行：

∂L/∂z = ∂L/∂h ⊙ [1, 1] = [−0.045, −0.054]

（⊙ 表示逐元素相乘。）

陷阱

如果某个 z 是负的，对应的梯度会变成 0，这条路就断了。 这就是「神经元死掉」的由来：一个 ReLU 神经元一旦长期输出 0，梯度永远是 0，再也不会被更新。

第 6 步：L 对 W₁ 的梯度

同样的模式，只是换了一层。W₁ 的输入是 x = [1, 2]。

但 W₁ 是 2×2 的矩阵，四个元素各有各的梯度。逐个算：

∂L/∂W₁[0][0] = ∂L/∂z₀ × x₀ = (−0.045) × 1 = −0.045
∂L/∂W₁[0][1] = ∂L/∂z₀ × x₁ = (−0.045) × 2 = −0.090
∂L/∂W₁[1][0] = ∂L/∂z₁ × x₀ = (−0.054) × 1 = −0.054
∂L/∂W₁[1][1] = ∂L/∂z₁ × x₁ = (−0.054) × 2 = −0.108

排成矩阵：

表 D-2　W₁ 的梯度（行是 z 的分量，列是 x 的分量）
x₀ = 1x₁ = 2
∂L/∂z₀ = −0.045−0.045−0.090
∂L/∂z₁ = −0.054−0.054−0.108
∂L/∂W1 = [[−0.045, −0.090], [−0.054, −0.108]]
为什么是「外积」

这个构造叫外积：左边每一行乘右边每一个元素，铺成一张表。 每一行来自「上一层传来的梯度」，每一列来自「这一层的输入」。 矩阵形式写成 np.outer(dz1, x)，或者更常见的形式 x.T @ dz1（批量时）。

第 7 步：偏置的梯度

偏置最简单，因为 b 只和一个数相加，导数就是 1：

∂L/∂b₁ = ∂L/∂z = [−0.045, −0.054]
∂L/∂b₂ = ∂L/∂ŷ = −0.09

这就是为什么代码里偏置的梯度常常写作 dz.sum(0)——批量时把每个样本的梯度加起来。

D.4 更新参数，再算一次

所有梯度都齐了。用 η = 0.1 更新，规则是「往梯度的反方向走」：

W ← W − η · ∂L/∂W

逐个算：

W₂₀ = 0.5 − 0.1 × (−0.045) = 0.5 + 0.0045 = 0.5045
W₂₁ = 0.6 − 0.1 × (−0.099) = 0.6 + 0.0099 = 0.6099
W₁ = [[0.1, 0.2], [0.3, 0.4]] − 0.1 × [[−0.045, −0.090], [−0.054, −0.108]]
　 = [[0.1045, 0.2090], [0.3054, 0.4108]]

注意方向：梯度是负的，所以参数变大。这符合直觉——ŷ 太小了，要让输出变大。

再前向一次，看损失降了没有

z₁ = 0.1045 × 1 + 0.2090 × 2 = 0.5225
z₂ = 0.3054 × 1 + 0.4108 × 2 = 1.1270
h = [0.5225, 1.1270]（都为正，ReLU 放行）
ŷ = 0.5045 × 0.5225 + 0.6099 × 1.1270 = 0.2636 + 0.6874 = 0.9510
L = ½(0.9510 − 1)² = 0.00120
这就是训练

损失从 0.00405 降到 0.00120，一步降了 70%。 所有深度学习训练都是这个循环：前向 → 反向 → 更新 → 再前向。 区别只是网络大小和步数。

D.5 把这一遍压缩成公式

回头看第 4 章那套公式，你会发现每一行都对应刚才的一步。

第 4 章的公式对应刚才哪一步数值（这个例子）
dZ = p − yD.3 第 1 步−0.09
dW2 = HTdZD.3 第 3 步[−0.045, −0.099]
dH = dZW2TD.3 第 4 步[−0.045, −0.054]
dHpre = dH ⊙ 𝟙[H > 0]D.3 第 5 步[−0.045, −0.054]
dW1 = XTdHpreD.3 第 6 步[[−0.045,−0.09],[−0.054,−0.108]]

公式里的 HTdZ 之所以是转置，是因为要凑出「外积」的形状。 单样本时它就是 dz × h；批量时 h 变成 (n, h) 的矩阵，转置之后才能和 dz 相乘。

一句话记住反向传播

从损失出发，每一步问「上一层是谁乘出来的」，把上游梯度乘上「对方的数值」，一直乘到最底层。
算权重梯度时乘「输入」，算输入梯度时乘「权重」——两者永远交换。

D.6 用代码验证这一遍

二十行代码，跑出来的数字应该和上面完全一致：

import numpy as np

x  = np.array([1.0, 2.0])
W1 = np.array([[0.1, 0.2], [0.3, 0.4]])
W2 = np.array([[0.5], [0.6]])
y, lr = 1.0, 0.1

# 前向
z1 = W1 @ x
h  = np.maximum(0, z1)
yhat = float((W2.T @ h)[0])
L = 0.5 * (yhat - y) ** 2
print("yhat", yhat, "L", L)

# 反向
dyhat = yhat - y
dW2 = dyhat * h.reshape(-1, 1)      # 上游梯度 × 输入
dh  = W2.flatten() * dyhat          # 上游梯度 × 权重
dz1 = dh * (z1 > 0)                # 穿过 ReLU 的开关
dW1 = np.outer(dz1, x)              # 上游梯度 × 输入

print("dW2", dW2.ravel())
print("dW1\n", dW1)

# 更新
W1 -= lr * dW1
W2 -= lr * dW2

输出：

yhat 0.91 L 0.004049999999999997
dW2 [-0.045 -0.099]
dW1
 [[-0.045 -0.09 ]
 [-0.054 -0.108]]

和手算一致。现在那五行公式对你来说不是符号了，是刚才走过的五步。

D.7 回到 10 万参数

你可能会问：这个例子只有 9 个参数，本项目有 100,048 个，差了一万倍，能一样吗？

完全一样。差别只在三处：

这个例子本项目
每层的宽度264 / 232
层数22（每个解码器层含注意力 + FFN）
中间的子层只有矩阵乘和 ReLU注意力、残差、LayerNorm、FFN

前两处只是数字变大，公式一个字不用改。

第三处才是真正的区别：Transformer 的每一层内部有更多的「运算节点」，反向传播要多穿几道门。 但每道门都遵守同一个规则——上游梯度乘本地导数。残差是加法（导数 1），LayerNorm 有自己的公式， 注意力里有 softmax（第 3 章推过：dz = p − y）。

要点

反向传播的复杂度不在于层数多，而在于每层的「本地导数」长什么样。 把这个 9 参数的网络推通，剩下的就是为每种新运算补一条本地导数而已。

D.8 几个容易卡住的地方

为什么要从后往前，不能从前往后？

因为你要算的是 L 对每个参数的导数，而 L 在最末尾。 从前往后的话，算到第一层时你还不知道最后的 L 是多少，没法用链式法则。

从后往前，每走一步都知道「上游已经累积了多少影响」，只要乘上本地导数就行。 这是唯一可行的方向，不是习惯。

梯度为什么能"乘"？

因为链式法则：

∂L/∂a = ∂L/∂b × ∂b/∂a

它的意思是「a 变一点，先影响 b，b 再影响 L」。 两次影响的比例相乘，就是总的影响比例。这和高中学的复合函数求导是同一条法则。

为什么代码里用 += 而不是 =

因为一个变量可能被用了两次。比如 y = x * x，x 通过两条路影响 y， 两条路的梯度都要算进来，所以是累加。

写成 = 会让后一次覆盖前一次，结果只有正确值的一半。这是手写 autograd 最经典的 bug。

为什么要对 batch 取平均

因为损失定义成了「平均」：L = (1/n)ΣLᵢ。求导时那个 1/n 会保留下来， 所以每个样本的梯度加起来之后要除以 n。

取平均还是求和，只影响梯度的尺度，不影响方向——本质上会被学习率吸收。

这一节想让你带走的

  1. 前向是代入，反向是链式法则。没有第三种魔法。
  2. 权重的梯度 = 上游梯度 × 输入；输入的梯度 = 上游梯度 × 权重。两者永远交换。
  3. ReLU 的导数是个开关，负数区把梯度截断成 0。
  4. 一次完整的训练 = 前向 + 反向 + 更新。本例中损失一步降了 70%。
  5. 9 个参数和 10 万个参数，公式一模一样。只是矩阵变大，外加更多类型的「本地导数」。

练习

  1. 不看正文，在纸上把 D.2 到 D.4 完整走一遍。每一步都写下数字，最后和文中核对。
  2. 把学习率改成 0.5，重算一次更新。损失降得更多还是更少？再试 2.0，看会不会发散。
  3. 把输入改成 x = [−1, 2]，重算前向。这时 z₁ 会变成负数， 反推时 ReLU 会截断哪一条路？对 W₁ 的梯度有什么影响？
  4. 把输出层也加一个 ReLU（即 ŷ = ReLU(W₂h)），重推一遍。此时 ∂L/∂ŷ 还等于 ŷ − y 吗？
  5. （进阶）把损失换成 L = |ŷ − y|。在 ŷ = 0.91 处，梯度是多少？ 如果 ŷ 恰好等于 y 呢？绝对值在 0 点不可导——这是它不如平方好用的原因。
