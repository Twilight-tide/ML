你已经会矩阵乘法了——考试考过，分数还不低。但考试里的矩阵乘法是「算出这个结果」， 机器学习里的矩阵乘法是「这个结果代表什么」。这两件事之间隔着一层翻译，而这一章就是那层翻译。 学完它，你看 Q @ K.T 时看到的将不再是数字，而是「每个位置在向其他所有位置问：你和我有多相关」。

2.1 三个必须建立的映射

整个深度学习，说到底只有三个映射反复出现。它们简单到你会觉得「这不是废话吗」，但正是它们撑起了后面所有推导。

表 2-1　三个映射
数学对象机器学习里的含义在第几章用到
向量 x ∈ ℝd一个对象的特征表示。d 个数字描述它贯穿全书
矩阵乘 Wx一次线性变换：换坐标系、投影、加权求和§3.2 的 WQ,WK,WV
内积 q·k相似度。两个向量的方向有多接近式(1) 的核心

第一个映射最容易接受：一张 8×8 的手写数字图片，拉直就是 64 维向量；一个字符的嵌入，就是 64 维向量。 向量不是「一组数」，是「一个东西的坐标」。

第二个映射需要一点想象。Wx 不是「把 x 变成 y」，而是「把 x 放到另一个坐标系里看」。 如果 W 是一个把第 1、2 维混合的矩阵，那么变换后的每一维都是原来所有维的加权和。 论文里的 WQ 做的就是这件事：把「字符的语义向量」变成「用于查询的向量」。 同一个 x，经过三个不同的 W，就得到三种不同的「视角」。

第三个映射是这一章的核心，值得单独一节。

2.2 内积为什么能表示相似度

内积的定义你熟悉：

q · k = Σi qi ki = ‖q‖ ‖k‖ cos θ θ 是两个向量的夹角

右边那个等号是关键。它把内积拆成了两部分：长度（‖q‖‖k‖）和方向（cos θ）。 只看方向的话，内积就是 cos θ 乘以两个长度。方向越接近，cos θ 越接近 1，内积越大；垂直时 cos θ = 0，内积为零。

换个角度看，内积还等于「q 在 k 方向上的投影长度」乘以「k 的长度」：

q · k = (‖q‖ cos θ) · ‖k‖ 括号里就是 q 在 k 方向上的投影

所以「内积大」的意思是：q 有很大一部分落在 k 的方向上。如果 k 代表「这是一个函数定义的开头」， q 代表「我现在想找一个函数名」，那么内积大就表示「我现在需要的，恰好是你提供的那种信息」。

要点

注意力机制的全部计算，起点就是一个内积：q·k。 它回答的问题只有一个：位置 i 需要的「查询」，和位置 j 提供的「键」，有多匹配。 匹配度高，就给 j 更大的权重。就这么简单。

这里有个容易被忽略的细节：内积同时受方向和长度影响。如果某个 k 的模长特别大， 它跟谁的內积都会偏大——这不合理，因为「长度」不代表「更相关」。 这就是为什么后面要用余弦相似度做归一化，也是为什么注意力里要除以 √dk（第 6 章会从方差的角度重新推一遍）。

2.3 numpy 的八个动作

不需要学完 numpy。整个项目用到的只有八个动作，下面这张表可以贴在显示器上。 不过在贴之前，得先把表里反复出现的那个词说清楚。

先搞清楚 axis 是什么

一个数组可以有几个「方向」。一维数组沿一条线排开，只有一个方向；二维数组铺在一个平面上，有横向和纵向两个方向；三维数组（也叫张量）占满一块空间，有三个方向。 每一个这样的方向，就叫一个「轴」，英文 axis。

轴从 0 开始编号。所以 shape 和 axis 说的其实是同一件事的两面：

shape = (3, 4)
⟺
axis 0 长度 3
axis 1 长度 4

shape 告诉你每个轴有多长，axis=k 告诉你「要操作第 k 个轴」。 看到 (3, 4)，就该知道它有两个轴：0 和 1，不存在 axis 2。

为什么不用「行」和「列」？因为维度一旦超过 2，「行」「列」就不够用了—— 三维张量没有第三个数可以叫。用数字编号，不管几维都能一直数下去。

那为什么函数非要你写 axis？因为不写就有歧义。一张 3×4 的表求和， 是每列各求一个和（得 4 个数），还是每行各求一个和（得 3 个数）？ 两种都说得通，numpy 不替你猜。

要点

axis 就是「数组的第几个方向」，从 0 开始数。 一维数组只有一个轴（axis 0），二维有两个，三维有三个。 判断结果形状的规则只有一条：哪个轴被操作了，结果里就没有它。

动作作用在注意力里的位置
np.array(...)建数组到处都是
.shape看形状，返回元组调试第一件事
.reshape(...)改形状，不改数据顺序拆头：(B,T,d) → (B,T,h,d_k)
.transpose(...) / .T交换维度拼头、算 K.T
@ / np.matmul矩阵乘（批量也支持）式(1) 的 Q @ K.T
.sum(axis=)沿某轴求和softmax 的分母
.max(axis=)沿某轴取最大softmax 减 max
广播形状不同的数组自动对齐（下面单独讲）scores / sqrt(d_k)
陷阱

axis 的方向是最容易搞混的。axis=0 是「沿着行往下走」，结果是消掉行维度；axis=-1 是「沿着最后一维走」。 记住一句话：axis 指的是「被消掉的那一维」，不是「保留的那一维」。 softmax 永远在最后一维做，因为那是「对所有候选打分」的方向。

广播是怎么回事

看这段代码，猜形状：

import numpy as np

scores = np.random.randn(2, 3)        # 形状 (2, 3)
scores = scores / np.sqrt(16)       # 标量，无形状，随便除

m = scores.max(axis=-1, keepdims=True)  # 形状 (2, 1)
out = scores - m                       # (2,3) - (2,1) → (2,3)

(2,3) - (2,1) 之所以能算，是因为形状为 1 的那一维会被拉伸成 3 份。 这就是广播：先右对齐，再从右往左比较，要么相等，要么其中一个是 1。 keepdims=True 的唯一作用就是保住这个 1，让广播能对齐——去掉它，m 会变成形状 (2,)，减法就会沿错误的轴广播，得到完全错误的结果。

陷阱

忘记 keepdims=True 是 softmax 实现里最高频的 bug，而且它不报错，只是结果悄悄变错。 如果你的 attention 权重行和不为 1，先查这里。

2.4 手写 softmax，以及那个必须减掉的 max

softmax 把一个任意实数向量变成概率分布：

softmax(x)i = exi / Σj exj 输出全部为正，且求和为 1

它的作用是把「分数」变成「权重」。分数差距越大，输出越接近 one-hot；差距越小，输出越接近均匀分布。

现在写代码。第一版直觉写法：

def softmax_naive(x):
    e = np.exp(x)
    return e / e.sum(axis=-1, keepdims=True)

试一下：

>>> softmax_naive(np.array([1.0, 2.0, 3.0]))
array([0.09003057, 0.24472847, 0.66524096])   # 求和 = 1，正确

>>> softmax_naive(np.array([1000.0, 1001.0, 1002.0]))
array([nan, nan, nan])                        # 炸了

原因：np.exp(1000) 超出浮点数上限，变成 inf；inf / inf 就是 nan。 float64 的上限约 1.8×10308，取对数得 709——任何超过 709 的输入都会溢出。float32 更惨，阈值只有 88。

修法是把分子分母同时除以 em，其中 m 是这一行的最大值：

exi−m / Σj exj−m = (exi · e−m) / (Σj exj · e−m) = exi / Σj exj

这是一个恒等变形，数学上结果完全不变。但数值上，减完之后最大值变成 0， 最大的项是 e0=1，其余项都 ≤ 1，永远不会溢出。而非常小的项会下溢成 0，这没关系——它本来就该是 0。 

def softmax(x, axis=-1):
    """数值稳定的 softmax。"""
    x = x - x.max(axis=axis, keepdims=True)   # 关键：减去最大值
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

>>> softmax(np.array([1000.0, 1001.0, 1002.0]))
array([0.09003057, 0.24472847, 0.66524096])   # 和 [1,2,3] 结果一模一样

注意最后一行：[1000,1001,1002] 和 [1,2,3] 的 softmax 结果完全相同。 这不是巧合，是 softmax 的一个性质——它只看相对差距，不看绝对大小。整体平移输入，输出不变。

要点

softmax 对所有输入加同一个常数，输出不变。这个性质在后面的温度采样里会再用到（除以温度等价于缩放差距）， 也是第 6 章「为什么要除以 √dk」的反面——除以 √dk 是改变差距的尺度，而不是平移。

2.5 手写矩阵乘法

写一遍三重循环，你会永远记住 (n,m) @ (m,p) → (n,p) 里那个 m 必须相等：

def matmul_naive(A, B):
    n, m = A.shape
    m2, p = B.shape
    assert m == m2, f"形状不匹配: {A.shape} @ {B.shape}"

    C = np.zeros((n, p))
    for i in range(n):
        for j in range(p):
            s = 0.0
            for k in range(m):
                s += A[i, k] * B[k, j]    # 第 i 行 · 第 j 列
            C[i, j] = s
    return C

A = np.random.randn(3, 4)
B = np.random.randn(4, 5)
assert np.allclose(matmul_naive(A, B), A @ B)

现在把它和注意力联系起来。Q @ K.T 里，Q 的每一行是一个查询向量，K.T 的每一列是一个键向量， 所以结果的第 (i, j) 个元素就是「第 i 个查询和第 j 个键的内积」。 一个矩阵乘法，一次性算出了所有位置两两之间的相似度。

这就是 Transformer 能并行的根本原因：RNN 必须一个时间步一个时间步地传状态，而注意力把所有位置的关系一次性算完。

动手

用 np.random.randn(1, 4, 6) @ np.random.randn(1, 6, 4) 试一下。 你会得到 (1, 4, 4)——批量矩阵乘对前导维度自动广播。 注意力正是靠这个性质，一次处理整个 batch 的所有头。

2.6 线性回归：解析解与迭代解的第一次对照

现在把前面所有东西串起来，做一个最小的机器学习问题。它简单到有闭式解，因此可以验证你的梯度下降写对了没有—— 这是全书唯一一次你能拿到「标准答案」的机会。

问题：给 200 个样本，每个样本 3 个特征，找一个 w 使得 Xw 尽量接近 y。损失用均方误差：

L(w) = (1/n) ‖Xw − y‖² n 是样本数

对 w 求导并令其为零，得到正规方程：

∇L = (2/n) XT(Xw − y) = 0 ⟹ w = (XTX)−1 XTy

完整代码：

import numpy as np
np.random.seed(0)

# ---- 造数据：y = X · w_true + 噪声 ----
n, d = 200, 3
X = np.random.randn(n, d)
w_true = np.array([2.0, -1.0, 0.5])
y = X @ w_true + 0.1 * np.random.randn(n)

# ---- 解法一：正规方程（解析解）----
w_ls = np.linalg.solve(X.T @ X, X.T @ y)
# 用 solve 而不是 inv：数值上更稳，也更快

# ---- 解法二：梯度下降（迭代解）----
w_gd = np.zeros(d)
lr = 0.1
losses = []
for step in range(300):
    pred = X @ w_gd
    loss = ((pred - y) ** 2).mean()
    losses.append(loss)
    grad = 2 * X.T @ (pred - y) / n     # 就是上面推的那个公式
    w_gd -= lr * grad

print("真值  ", w_true)
print("解析解", w_ls)
print("梯度下降", w_gd)
print("最大差值", np.abs(w_ls - w_gd).max())

输出：

真值   [ 2.  -1.   0.5]
解析解 [ 1.99919694 -0.99475108  0.49332657]
梯度下降 [ 1.99919694 -0.99475108  0.49332657]
最大差值 3.1e-09

两个完全不同的方法，收敛到同一个点，误差在 1e-9 量级。 这是一个非常重要的心理锚点：梯度下降不是玄学，它是一个确实能找到最优解的算法。 后面所有神经网络训练——包括 Transformer——用的都是同一个套路，只是损失函数变复杂了，梯度不再有闭式解。

要点

三步走：定义损失 → 求梯度 → 沿负梯度更新。 第 3 章会把这个套路用在分类上，第 4 章会把它自动化（反向传播），第 9 章会用在学习率调度上。 你现在看到的这条循环，是全书的骨架。

陷阱

学习率取 1.0 试试。你会发现 loss 变成 nan。 梯度下降的稳定条件是 lr < 2/L，L 是损失函数的 Lipschitz 常数（这里约等于 XTX 的最大特征值 × 2/n）。 学习率太大会让参数在最优解两侧来回震荡，幅度越来越大。第 9 章会讲论文怎么用 warmup 绕开这个问题。

2.7 这一章你要带走的

把这三样东西记住，后面九章都会反复用到：

  1. 内积 = 相似度。它衡量两个向量方向的一致程度。注意力的一切从这里开始。
  2. softmax 只看相对差距，必须减 max。减 max 是恒等变形，但不减就会溢出。
  3. 训练 = 定义损失 + 求梯度 + 更新。解析解只在极简问题里存在，之后全靠梯度下降。

本章要点

  1. 向量是「一个东西的坐标」，矩阵乘是「换一个坐标系看它」，内积是「两个坐标方向有多接近」。
  2. 内积 = ‖q‖‖k‖cos θ，本质是投影。它同时受长度和方向影响，这是后面要归一化的原因。
  3. softmax 减 max 是恒等变形，数值上把最大指数压到 0，避免 inf/nan。float32 的溢出阈值只有 88。
  4. axis 指「被消掉的维」；keepdims=True 保住那个 1，否则广播会沿错误的轴进行。
  5. 正规方程和梯度下降在凸问题上收敛到同一点，误差 1e-9。这是验证梯度是否写对的黄金标准。
