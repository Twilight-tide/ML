模型、损失、优化，以及一个干净得不像话的梯度

上一章你用手算的梯度让一个模型收敛了。但那个问题太简单——损失是平方，梯度是线性的， 最优解还有闭式公式。真实问题不长这样。这一章要处理第一个「没有闭式解」的问题：分类。 在解决它的过程中，你会遇到一个结果极其简洁的导数，而整个 Transformer 的训练，本质上就是把那个导数算了几亿次。

3.1 一切监督学习都是同一个三元组

不管模型多复杂，结构永远是这三件事：

假设空间
模型能表达什么
→
损失函数
错了有多错
→
优化算法
怎么改参数

线性回归的假设空间是「所有线性函数」，损失是 MSE，优化是正规方程或梯度下降。 逻辑回归的假设空间是「所有线性函数 + sigmoid」，损失换成交叉熵，优化还是梯度下降。 Transformer 的假设空间是「所有 2 层注意力网络」，损失是交叉熵，优化是 Adam + warmup。

结构和算法在变，三元组从没变过。所以读任何一篇深度学习论文，都可以先问这三个问题：

  1. 它的模型能表达什么？（假设空间）
  2. 它优化什么目标？（损失）
  3. 它怎么优化？（算法、学习率、正则）

论文 §3 回答第一个，§5.3 部分回答第二和第三个。你以后每读一篇新论文，先找这三样，能省一半时间。

3.2 从回归到分类：加一个 sigmoid 就够了

分类问题的输出应该是概率，但线性模型的输出是任意实数。解决办法是套一个函数把 ℝ 压到 (0, 1)：

σ(z) = 1 / (1 + e−z) sigmoid，也叫 logistic 函数

它有几个讨喜的性质：σ(0) = 0.5，z → +∞ 时趋于 1，z → −∞ 时趋于 0，而且导数有一个漂亮的形式：

σ′(z) = σ(z)(1 − σ(z)) 求导时分子分母同乘 e^z 即可验证

这个性质意味着：导数可以用函数值本身算出来，不需要重新计算指数。 当你已经算过 p = σ(z)，梯度就是 p(1−p)，几乎免费。这在反向传播里非常有用。

陷阱

直接写 1 / (1 + np.exp(-z)) 在 z = −1000 时会溢出（exp(1000) = inf）。 和 softmax 一样需要数值稳定写法。稳妥版本：当 z ≥ 0 时用 1/(1+exp(-z))， 否则用 exp(z)/(1+exp(z))。实践中直接调 scipy.special.expit 最省事。

3.3 为什么分类不用均方误差

既然 MSE 在回归里好用，为什么分类要换成交叉熵？两个理由，第二个更重要。

理由一：MSE 配 sigmoid 会梯度消失

设 p = σ(z)，用 MSE 时 L = (p − y)²，对 z 求导：

∂L/∂z = 2(p − y) · σ′(z) = 2(p − y) · p(1 − p)

假设真实标签 y = 1，模型却给了 p = 0.01（错得很离谱）。梯度约为 2 × (−0.99) × 0.01 × 0.99 ≈ −0.02。 错得越离谱，梯度反而越小——因为 p(1−p) 在两端趋于 0。模型在最该被纠正的时候，学得最慢。

理由二：交叉熵是最大似然的直接结果

换个角度推。二分类的似然是：

P(y | x) = py(1−p)1−y y=1 时取 p，y=0 时取 1−p

取负对数，就是交叉熵：

L = −[ y log p + (1 − y) log(1 − p) ]

交叉熵不是「发明」出来的，是「推导」出来的。它等于「在模型给出的分布下，真实标签出现的概率的负对数」。 最小化它，就是最大化「模型给正确答案的概率」。

多分类时它是：

L = −Σi yi log pi y 是 one-hot，所以实际上只有正确类别那一项非零

换句话说：多分类交叉熵 = −log(模型给正确类别的概率)。 模型给正确答案 0.9，损失 0.105；给 0.1，损失 2.303。这个数量级你在第一章的日志里见过。

3.4 那个干净得不像话的梯度

现在推一个全书最重要的公式。先把上一节那个 z 正式命名： 模型最后一层输出的原始分数叫 logits，它可以是任意实数，还不是概率； softmax 把它变成概率 p。分数和概率，从此分开。

设 logits 为 z，经过 softmax 得到 p，损失用交叉熵：

pi = ezi / Σj ezj， L = −Σi yi log pi

第一步，算 softmax 的雅可比。对 zj 求导要分两种情况：

∂pi/∂zj = pi(1 − pi)　若 i = j
−pipj　　　　　　若 i ≠ j 可以合并写成 ∂p_i/∂z_j = p_i(δ_ij − p_j)，δ 是克罗内克符号

第二步，链式法则：

∂L/∂zj = −Σi (yi/pi) · ∂pi/∂zj = −Σi (yi/pi) · pi(δij − pj)

约掉 pi：

= −Σi yi(δij − pj) = −yj + pj Σi yi

而 y 是 one-hot，Σ yi = 1，于是：

∂L/∂z = p − y 式(3-1)　softmax + 交叉熵的梯度
要点

这个结果值得盯十秒钟。它说：梯度就是「预测分布」减去「真实分布」。 模型说 [0.7, 0.2, 0.1]，真相是 [1, 0, 0]，梯度就是 [−0.3, 0.2, 0.1]—— 把正确类往上推 0.3，把错误类往下压。没有任何多余的项，没有 σ′，没有分母。

整个 Transformer 训练时，反向传播的第一站就是它。你后面读到 lossf(logits.view(-1, V), y.view(-1)) 时， 脑子里应该立刻浮现 p − y 这个式子。

顺带一提，这也解释了为什么交叉熵配 softmax 不会有 MSE 那样的梯度消失： p(1−p) 那个因子被约掉了。这是「损失函数要和输出层匹配」这个原则最经典的例子。

3.5 梯度下降的三种形态

表 3-1　按每次用多少样本算梯度来分
名称每次用优点缺点
批量 GD全部样本梯度准，曲线平滑大数据集跑不动，无法在线学习
随机 GD1 个样本极快，能跳出局部极小梯度噪声大，loss 抖得厉害
小批量32 / 64 / 256兼顾速度与稳定，能吃满 GPU多了一个超参 batch size

实践中几乎只用小批量，因为 GPU 是并行计算的——批太小浪费算力，批太大显存不够。 本项目用 32，论文用 25000 个 token（约 1000 个句子对）。batch size 的选择往往由显存决定，而不是由理论决定， 这一点在 8 GB 的笔记本上体会尤其明显。

标准的更新规则是：

θ ← θ − η ∇L(θ) η 是学习率

第 9 章会看到，论文用的不是这个朴素形式，而是 Adam + 一个精心设计的学习率曲线。 但底层逻辑完全一样：算出梯度，往反方向走一步。

3.6 过拟合：模型开始背答案

第一章你看到验证 loss 在 1750 步后停住了，而训练 loss 还在降。这就是过拟合： 模型在训练集上越来越好，在没见过的数据上不再变好。

判断方法只有一个，但必须严格执行：

数据集用途能不能用来调参
训练集 train算梯度、更新参数—
验证集 val挑超参、判断何时停能
测试集 test最终评估，只跑一次绝对不能
陷阱

如果你用测试集反复调超参，测试集就退化成了验证集，你最后报出的数字会系统性偏高。 这在论文里是严重的方法论错误，在课程作业里则是最常见的失分点。 规矩是：测试集只看一眼，看完就锁起来。

对付过拟合有四种手段，按性价比排序：

  1. 更多数据——最有效，但通常做不到。
  2. 正则化——给损失加一项 λ‖θ‖²，惩罚大权重。等价于「不鼓励模型对任何特征过度自信」。
  3. 早停——验证 loss 开始上升就停。简单粗暴，常被低估。
  4. Dropout——训练时随机把一部分神经元置零。论文 §5.4 用的就是这个，Pdrop=0.1。

注意本项目 src/config.py 里 dropout=0.1，和论文一致。 但 10 万参数的模型配 6 MB 语料，0.1 的 dropout 其实偏小——这就是为什么它会过拟合。

3.7 完整实现：手写逻辑回归

现在把所有东西拼起来。这段代码你能直接跑，用的是 scikit-learn 自带的数据集，不需要联网。

import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# ---------- 数据 ----------
X, y = load_breast_cancer(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.2, random_state=0, stratify=y)

# 标准化：让每个特征均值 0、方差 1。
# 不做的话梯度下降会因为特征尺度差异而震荡。
scaler = StandardScaler().fit(X_tr)
X_tr, X_te = scaler.transform(X_tr), scaler.transform(X_te)

# ---------- 模型 ----------
def sigmoid(z):
    """数值稳定版。"""
    out = np.empty_like(z, dtype=float)
    pos = z >= 0
    out[pos] = 1 / (1 + np.exp(-z[pos]))
    ez = np.exp(z[~pos])
    out[~pos] = ez / (1 + ez)
    return out

w = np.zeros(X_tr.shape[1])
b = 0.0
lr = 0.1

# ---------- 训练 ----------
for step in range(2000):
    z = X_tr @ w + b
    p = sigmoid(z)

    # 交叉熵（加 1e-9 防止 log(0)）
    loss = -(y_tr * np.log(p + 1e-9) +
             (1 - y_tr) * np.log(1 - p + 1e-9)).mean()

    # 梯度：p - y 再乘 x。（3.4 节的结论）
    grad_w = X_tr.T @ (p - y_tr) / len(y_tr)
    grad_b = (p - y_tr).mean()

    w -= lr * grad_w
    b -= lr * grad_b

    if step % 200 == 0:
        print(f"step {step:4d}  loss {loss:.4f}")

# ---------- 评估 ----------
acc = ((sigmoid(X_te @ w + b) > 0.5).astype(int) == y_te).mean()
print(f"测试集准确率: {acc:.4f}")

输出大致是：

step    0  loss 0.6931
step  200  loss 0.1024
step  400  loss 0.0834
...
测试集准确率: 0.9737

97.4%，和 sklearn.linear_model.LogisticRegression 差不到 1 个百分点。 如果你跑出来明显低于这个数，八成是梯度推错了或者忘了标准化。

3.8 距离 Transformer 还有多远

现在你有了：输入、线性变换、非线性、损失、梯度、更新。这套东西已经能训练一个分类器了。

Transformer 比它多三样东西：

  1. 多层堆叠——一个线性层不够，要 2 层、6 层、96 层。这就引出了反向传播（第 4 章）。
  2. 更复杂的结构——注意力、残差、归一化（第 6–8 章）。但它们的梯度仍然走同一条链。
  3. 序列——输入不是一个向量，而是一串 token，而且输出也是一串（第 5 章）。

就这三样。剩下的都是工程细节。

本章要点

  1. 一切监督学习 = 假设空间 + 损失函数 + 优化算法。读论文先找这三样。
  2. 分类用交叉熵不用 MSE，因为 MSE 配 sigmoid 会梯度消失，而交叉熵是最大似然的直接结果。
  3. softmax + 交叉熵的梯度 = p − y。全书最重要的公式之一，反向传播的起点。
  4. batch size 的选择在实践中由显存决定，而不是由理论决定。
  5. 测试集只能看一次。用它调参，报出的数字就是虚的。
