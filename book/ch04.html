这一章是全书的关卡。前面三章你还能靠直觉蒙混过去，从这里开始不行了。 读完它，你应该能在白纸上写出一个两层网络的完整反向传播，包括每一个矩阵的形状。 做不到，就先别往下走——第五章之后的每一行代码，都建立在这套推导上。

4.1 为什么一层不够

先回答一个容易被跳过的问题：既然线性层加 sigmoid 已经能做分类，为什么还要堆两层、六层、九十六层？

因为线性变换的复合还是线性变换：

W2(W1x) = (W2W1)x = Wx

两个线性层叠起来，等价于一个线性层。堆一百层也一样。所以深度本身不带来任何表达能力， 直到你在中间插入一个非线性函数。

这就是激活函数存在的全部理由。它不是「模仿神经元放电」这种浪漫说法，而是一个数学上的必需： 没有它，网络退化成一个线性模型。

要点

深度 + 非线性 = 表达能力。缺一个都不行。 论文里 FFN 用 ReLU（式 2），注意力里的 softmax 也是非线性——整个 Transformer 的非线性全靠这两处。

4.2 一个神经元的三种写法

同一个计算，三种写法，都要认得出是同一个东西：

z = w · x + b　　⟺　　 z = Σi wixi + b　　⟺　　 z = Wx + b 标量内积 / 逐元素求和 / 矩阵形式（一次算一个 batch）

左边是教科书里的写法，右边是代码里的写法。它们的区别只是「一次算一个样本」还是「一次算一批」。 第三种的 W 形状是 (dout, din)，x 是 (n, din)， 结果是 (n, dout)——注意 PyTorch 的 nn.Linear 存的就是这个方向的 W， 所以它内部算的是 x @ W.T + b。

4.3 计算图：把复合函数拆成加法乘法

看这个函数：

反向传播就是从 L 出发，沿着箭头倒着走，把每一步的局部导数乘起来。 链式法则说：

∂L/∂a = ∂L/∂(a·b) · ∂(a·b)/∂a

关键在于：每个节点只需要知道「我的输出对输入的局部导数」，然后把上游传来的梯度乘上去，再往下传。 它不需要知道整个函数长什么样。

这就是为什么自动微分能对任意深的网络工作：你只需要为每种运算定义一次局部导数 （加法、乘法、ReLU、exp、matmul……），剩下的由引擎自动串起来。

4.4 手写一个自动微分引擎

下面这段代码不到 60 行，但它是 PyTorch 的核心。Andrej Karpathy 的 micrograd 就是这个思路， 这里做了精简但保持可运行。 

class Value:
    """一个标量，同时记录它从哪来、怎么反传。"""

    def __init__(self, data, children=(), op=""):
        self.data = data
        self.grad = 0.0                      # dL/d(self)，初始为 0
        self._backward = lambda: None
        self._prev = set(children)          # 计算图上的父节点
        self._op = op

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), "+")

        def _backward():
            # 加法把梯度原样分给两边（注意用 +=，因为一个节点可能有多个消费者）
            self.grad  += out.grad
            other.grad += out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), "*")

        def _backward():
            # 乘法：梯度乘以对方的数值
            self.grad  += other.data * out.grad
            other.grad += self.data  * out.grad
        out._backward = _backward
        return out

    def relu(self):
        out = Value(max(0.0, self.data), (self,), "relu")

        def _backward():
            # 负数区梯度为 0，正数区原样通过
            self.grad += (out.data > 0) * out.grad
        out._backward = _backward
        return out

    def backward(self):
        # 1) 拓扑排序：保证每个节点在被用到之前已经算完
        topo, visited = [], set()

        def build(v):
            if v not in visited:
                visited.add(v)
                for child in v._prev:
                    build(child)
                topo.append(v)

        build(self)

        # 2) 从输出往回，逐个调用局部导数
        self.grad = 1.0            # dL/dL = 1
        for node in reversed(topo):
            node._backward()

    # 让 Value 支持 a - b、-a、a + 1 这类写法
    def __neg__(self):        return self * -1
    def __sub__(self, other): return self + (-other)
    def __radd__(self, other): return self + other
    def __rmul__(self, other): return self * other
    def __repr__(self):       return f"Value(data={self.data:.4f}, grad={self.grad:.4f})"

验证它和 PyTorch 一致：

import torch

# 同一个表达式：L = (a*b + c) * d
a, b, c, d = Value(2.0), Value(-3.0), Value(10.0), Value(-2.0)
L = (a * b + c) * d
L.backward()
print(a.grad, b.grad, c.grad, d.grad)
# 6.0 -4.0 -2.0 4.0

ta = torch.tensor(2.0, requires_grad=True)
tb = torch.tensor(-3.0, requires_grad=True)
tc = torch.tensor(10.0, requires_grad=True)
td = torch.tensor(-2.0, requires_grad=True)
tl = (ta * tb + tc) * td
tl.backward()
print(ta.grad, tb.grad, tc.grad, td.grad)

两行输出应该完全一致。PyTorch 的 autograd 本质上就是这个类，只是它操作的是张量而不是标量， 并且用 C++ 实现以追求速度。

陷阱

注意 += 而不是 =。如果一个节点被用了两次（比如 y = x * x）， 梯度必须累加。写成 = 会让第二次覆盖第一次，结果只有正确值的一半。 这是手写 autograd 最经典的 bug。

4.5 两层 MLP 的矩阵反向传播

标量版本好懂，但真实网络操作的是矩阵。现在把同样的思路扩到矩阵，这部分必须亲手推一遍。

前向

H = ReLU(XW1 + b1)
Z = HW2 + b2
L = CrossEntropy(softmax(Z), Y)

形状（n 个样本，d 维输入，h 维隐藏，c 类）：

张量形状说明
X(n, d)输入
W1(d, h)第一层权重
H(n, h)隐藏层激活
W2(h, c)第二层权重
Z(n, c)logits

反向，一步一步

第 0 步：损失对 logits 的梯度。直接用第 3 章的结论，并对 batch 取平均：

dZ = (softmax(Z) − Y) / n　　形状 (n, c)

第 1 步：对 W₂ 和 b₂。因为 Z = HW2 + b2， 所以 ∂Z/∂W₂ = H，梯度是「上游梯度左乘 H 的转置」：

dW2 = HT dZ　　(h,n)(n,c) → (h,c) ✓
db2 = Σ行 dZ　　沿 batch 维求和 → (c,)
要点

记住这个形状检验法：梯度的形状必须和参数本身一致。 W₂ 是 (h, c)，dW₂ 也必须是 (h, c)。而 HTdZ 是 (h,n)(n,c)=(h,c)，刚好对上。 如果你推出来的形状不对，不用往下看，肯定错了。

第 2 步：传到隐藏层。

dH = dZ W2T　　(n,c)(c,h) → (n,h) ✓

第 3 步：穿过 ReLU。ReLU 的导数是一个 0/1 掩码，逐元素相乘：

dHpre = dH ⊙ 𝟙[H > 0]

第 4 步：对 W₁ 和 b₁。和第 1 步完全对称：

dW1 = XT dHpre　　(d,n)(n,h) → (d,h) ✓
db1 = Σ行 dHpre　　→ (h,)

推完了。整个过程只有两个模式在重复：「梯度 = 上游梯度 × 本地导数」 和 「权重梯度 = 输入转置 × 上游梯度」。 六层的 Transformer 也是这两句话，只是重复更多次、中间多了注意力和 LayerNorm。

4.6 numpy 版与 PyTorch 版

为了让你确认自己真的懂，最有效的办法是用两种方式实现同一个网络，然后对比 loss 曲线。

numpy 版（核心部分）

def train_mlp_numpy(X, Y, d=64, h=128, c=10, lr=0.1, steps=2000):
    n = X.shape[0]
    # He 初始化：方差 2/fan_in，配合 ReLU
    W1 = np.random.randn(d, h) * np.sqrt(2.0 / d)
    b1 = np.zeros(h)
    W2 = np.random.randn(h, c) * np.sqrt(2.0 / h)
    b2 = np.zeros(c)

    for step in range(steps):
        # ---- 前向 ----
        Hpre = X @ W1 + b1
        H = np.maximum(0, Hpre)
        Z = H @ W2 + b2
        P = softmax(Z)

        # ---- 反向 ----
        dZ = (P - Y) / n                    # (n, c)
        dW2 = H.T @ dZ                      # (h, c)
        db2 = dZ.sum(0)
        dH = dZ @ W2.T                      # (n, h)
        dHpre = dH * (Hpre > 0)           # ReLU 掩码
        dW1 = X.T @ dHpre                   # (d, h)
        db1 = dHpre.sum(0)

        # ---- 更新 ----
        W1 -= lr * dW1;  b1 -= lr * db1
        W2 -= lr * dW2;  b2 -= lr * db2

    return W1, b1, W2, b2

PyTorch 版

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(64, 128),
    nn.ReLU(),
    nn.Linear(128, 10),
)
opt = torch.optim.SGD(model.parameters(), lr=0.1)
lossf = nn.CrossEntropyLoss()

for step in range(2000):
    logits = model(x)
    loss = lossf(logits, y)
    opt.zero_grad()
    loss.backward()      # ← 这里，numpy 版你手写的那 7 行
    opt.step()

PyTorch 版只有 5 行。loss.backward() 就是你在 4.5 节推的那整套东西， 它由 60 行 C++ 完成，但逻辑一模一样。

要点

当你能把 loss.backward() 展开成 7 行 numpy 时，你就不再是「调包的人」了。 后面读论文里任何复杂的梯度流（残差怎么传、LayerNorm 怎么反传），你都有能力自己推。

4.7 两个会让训练彻底失败的细节

初始化

如果所有权重初始化为 0，那么同一层的所有神经元永远算出相同的东西，梯度也相同，等于只有 1 个神经元。 所以必须随机初始化。但方差不重要——太小信号衰减，太大信号爆炸。

ReLU 网络的常用选择是 He 初始化：

W ∼ 𝒩(0, 2/din) 本项目 src/model.py 用的是 std=0.02 的正态，这也是 GPT 系列的惯例

梯度消失与梯度爆炸

反向传播是连乘。如果每一层的局部导数平均小于 1，乘 50 层就趋近于 0；大于 1 就炸成 inf。

∂L/∂h1 = ∂L/∂h50 · ∏i=1..49 ∂hi+1/∂hi

0.950 ≈ 0.005，1.150 ≈ 117。只要每层差 10%，50 层后就是两个数量级。

这直接引出 Transformer 的两个设计：

  • 残差连接（第 8 章）：x + f(x) 的导数含一个恒等项 +1，保证梯度有「高速公路」直达浅层。
  • LayerNorm（第 8 章）：把每层输出归一化到稳定范围，避免数值尺度逐层漂移。

论文里这两样东西各出现两次（每个子层一次），不是随便加的。

本章要点

  1. 线性层堆叠仍是线性，深度必须配非线性才有意义。
  2. 反向传播 = 拓扑排序 + 每个节点调用自己的局部导数 + 累加梯度。
  3. 两个反复出现的模式：权重梯度 = 输入转置 × 上游梯度；输入梯度 = 上游梯度 × 权重转置。
  4. 形状检验法：梯度的形状必须和参数完全一致，对不上就是推错了。
  5. 连乘导致梯度消失/爆炸。残差和 LayerNorm 就是为此而生。
