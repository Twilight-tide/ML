注意力的由来

RNN 的三个死穴，和 √d_k 的完整推导

约 2 周 本章是全书的枢纽 对应 W9–W10

前面五章，你已经能训练一个会写代码的模型了。但那个模型的上下文是死的——只看前 8 个字符， 而且位置信息被硬编码在拼接顺序里。这一章要换掉这个「读上下文」的机制。 换法只有一行公式，但你得先明白为什么非换不可，以及那一行里每个符号从哪来。

6.1 RNN 的三个死穴

在注意力之前，序列建模的主流是循环网络。它的思路是「用一个隐藏状态，从头读到尾」：

ht = tanh(Whht−1 + Wxxt)

这个式子里藏着三个问题，论文 §1 和 §4 都点名了：

死穴一：不能并行

要算 ht，必须先算完 ht−1。 一千年长度的序列就是一千次串行计算，GPU 的上万个核只能干看着。 这是工程问题，但它的代价极高——训练时间与序列长度成正比，而不是可以并行摊薄。

死穴二：长距离依赖的路径是 O(n)

第 1 个词的信息要传到第 1000 个位置，中间要经过 999 次非线性变换。 每次变换都会让梯度乘上一个小于 1 的因子，传到底层时早已消失。

要点

论文 §4 用「最大路径长度」来度量这个问题的严重性：

层类型每层复杂度最大路径长度
自注意力O(n²·d)O(1)
循环网络O(n·d²)O(n)
卷积O(k·n·d²)O(logk n)

自注意力的路径长度是 1——任意两个位置直接相连，不经过任何中间步骤。 这是它最重要的性质，比「能并行」更根本。

死穴三：信息瓶颈

整个过去必须被压缩进一个固定大小的向量 ht。 不管前面是一句话还是一本书，容量都一样。信息论上这是不可能的—— 你没法把 1000 个 token 无损压进 512 维。

Bahdanau 等人在 2014 年的机器翻译工作里正面解决了第三个问题： 不要压缩。让解码器在每一步，直接回头看编码器的所有位置，自己决定看哪里。

6.2 从「压缩」到「检索」

这个想法的转变很关键：

RNN 的做法注意力的做法
编码器的输出只用最后一个 hT保留全部 h1..T
解码器怎么用从 hT 里「回忆」对全部 h 加权求和
权重无（全压在一个向量里）每步动态计算

用一句话概括：把「记忆」换成「检索」。不要求模型记住一切，而是给它一个能随时查的档案柜。

Bahdanau 的原始打分函数是「加性」的：

score(hi, sj) = vT tanh(W1hi + W2sj) h 是编码器状态，s 是解码器状态

它要过两层线性变换再加 tanh，计算量大。Luong 等人后来发现，直接用内积效果差不多，而内积可以写成矩阵乘法：

score = q · k 一次 matmul 算完所有位置对
要点

论文选点积而不是加性，理由只有一条但很硬：矩阵乘法在 GPU 上极度高效。 同样的计算量，matmul 比逐元素的 tanh 快一到两个数量级。 深度学习里很多「设计选择」最后都是这个理由——不是数学上更优雅，而是硬件上更快。

6.3 式(1)：一行公式，四个符号

论文 §3.2.1 的定义：

Attention(Q, K, V) = softmax( QKT / √dk ) V 式(1)　Q、K、V 分别是查询、键、值的矩阵

拆开看，它是四步：

表 6-1　式(1) 的计算流程（B=batch, T=序列长度, d_k=每头维度）
步骤运算形状变化在做什么
1QKT(B,T,dk)·(B,dk,T) → (B,T,T)所有位置两两算相似度
2/ √dk不变把方差拉回 1
3softmax(·)不变，但每行和为 1把分数变成权重
4· V(B,T,T)·(B,T,dv) → (B,T,dv)按权重混合各位置的值

第 4 步值得多看一眼。结果是 (B, T, dv)——和 V 形状一样，和输入一样长。 注意力不改变序列长度，它只改变每个位置的内容：把「我自己的向量」换成「我关注的那些位置的加权平均」。

要点

注意力是一个「按相关性加权的信息混合」操作。 输入 T 个向量，输出 T 个向量，第 i 个输出是「所有输入向量的加权平均，权重取决于 i 和它们的关系」。 这是全书对注意力最准确的一句话，比「查询图书馆」的类比可靠得多。

6.4 Q、K、V 到底是什么

最常见的类比是图书馆：

Q 查询
我想找什么
×
K 键
我是什么标签
→
匹配度
→
V 值
我实际的内容

类比有用，但会在两个地方误导你：

  1. Q、K、V 不是三个不同的东西，是同一个 x 的三个不同投影。 Q=xWQ，K=xWK，V=xWV。 图书馆里书和查询是分开的，这里它们是同一批向量换了三副眼镜看。
  2. 「值」不是「内容」，是「要传递出去的信息」。 V 可以是任何东西，模型自己学。在自注意力里，它就是输入的另一份线性变换。

为什么要把同一个 x 投影三次？因为「我要找什么」和「我能提供什么」不是一回事。 拿代码举例：一个 def 可能「提供」的是「函数定义开始」这个信息， 但它「需要」的是「接下来的函数名该叫什么」。这两个角色必须用不同的参数来编码。

如果 Q、K 用同一套权重，模型就只能表达「对称的相似度」——A 觉得 B 像自己，B 也必须觉得 A 像自己。 在语法结构里这种对称性是不成立的。

6.5 为什么除以 √d_k

这是论文里最容易被略过的一句话，也是面试最爱问的。原文只说「当 dk 较大时，点积的幅度会变大， 把 softmax 推入梯度极小的区域」。现在我们把这句话算出来。

第一步：q·k 的方差是 d_k

假设 q 和 k 的每个分量独立，均值 0、方差 1（这是初始化后的典型状态）。那么：

q·k = Σi=1dk qiki

先看均值。因为独立且均值为 0：

E[q·k] = Σi E[qi]E[ki] = 0

再看方差。同样因为独立，乘积的方差可以逐项相加：

Var(q·k) = Σi Var(qiki) = Σi E[qi²]E[ki²] = Σi 1 · 1 = dk

所以标准差是 √dk。dk = 512 时，内积的典型量级是 ±22（√512 ≈ 22.6）。

第二步：softmax 会饱和

把 22 量级的分数丢进 softmax 会发生什么？看这个例子：

>>> softmax(np.array([0, 22, -22]))
array([2.8e-10, 1.0, 2.8e-10])      # 几乎就是 one-hot

输出几乎是 [0, 1, 0]。而 softmax 的雅可比是 pi(δij − pj)， 当 p 接近 one-hot 时，几乎所有项都接近 0：

p = [0, 1, 0] ⟹ ∂p/∂z ≈ 全零矩阵

梯度消失了。模型再也学不动。这就是论文说的「推入梯度极小的区域」。

第三步：除以 √d_k 把方差拉回 1

如果除以 √dk，那么：

Var( q·k / √dk ) = dk / dk = 1

方差恒为 1，与 dk 无关。softmax 的输入始终在 ±2 的量级， 既不会饱和成 one-hot，也不会平得像均匀分布。不管你把 dk 调到 16 还是 512，注意力的行为都稳定。

陷阱

那为什么不除以 dk？那样方差会变成 1/dk，dk=512 时是 0.002。 softmax 的输入全挤在 0 附近，输出接近均匀分布 [1/T, …, 1/T]—— 注意力退化成「平均所有位置」，等于什么都没看。 除以 √dk 恰好是那个「既不太尖也不太扁」的点。

6.6 亲手验证

这段代码是本章的核心实验，务必跑一遍。它会让你对 √dk 的理解从「记住」变成「算过」。

import torch, math

torch.manual_seed(0)

print(f"{'d_k':>5} {'std(q·k)':>10} {'理论√d_k':>10} {'softmax最大值':>14} {'熵':>8}")
for d_k in [4, 16, 64, 256, 512]:
    q = torch.randn(4096, d_k)
    k = torch.randn(4096, d_k)
    dots = (q * k).sum(-1)                 # 4096 个内积

    # 不缩放：看 softmax 有多尖
    p_raw = torch.softmax(dots, dim=-1)
    # 缩放后
    p_scaled = torch.softmax(dots / math.sqrt(d_k), dim=-1)

    ent = -(p_scaled * p_scaled.log()).sum()
    print(f"{d_k:>5} {dots.std():>10.2f} {math.sqrt(d_k):>10.2f} "
          f"{p_raw.max():>14.4f} {ent:>8.2f}")

预期输出（数值会有小差异）：

  d_k  std(q·k)  理论√d_k   softmax最大值       熵
    4      2.00       2.00         0.0203     3.31
   16      4.00       4.00         0.0904     4.12
   64      7.98       8.00         0.5220     4.86
  256     15.98      16.00         0.9975     1.02
  512     22.55      22.62         1.0000     0.09

这张表把整件事说完了：

  • 第二列和第三列几乎相等——方差确实是 dk，推导没错。
  • 第四列在爆炸——dk=512 时 softmax 最大值是 0.99997，已经是一个 one-hot 了。
  • 第五列在坍缩——熵从 4.86 掉到 0.09，意味着分布几乎没有不确定性，梯度也就几乎没有。
动手

把 p_raw 换成 p_scaled，再看第四列和第五列。 你会看到它们在不同 dk 下基本持平——这就是缩放的全部意义： 让注意力的行为与维度解耦。

6.7 关于「注意力」这个词

这个词容易让人以为模型在「集中精神」。实际上它做的是一次加权平均， 权重由内积算出。所谓「学会了注意某个位置」，指的是那个位置的权重接近 1。

它没有任何主动的「选择」过程，也没有循环或搜索。就是三步：算相似度、归一化、加权求和。 简单到你会怀疑它为什么有效。

为什么有效？因为它给了模型一个 O(1) 的路径去访问任意位置的信息， 而且这条路径的权重是根据内容动态计算的，不是固定的。 RNN 的路径是固定的（只能顺着传），卷积的感受野是固定的（只能看邻居），只有注意力是内容寻址的。

本章要点

  1. RNN 三个死穴：不能并行、路径长度 O(n)、固定大小的信息瓶颈。注意力解决的是后两个。
  2. 核心思想是「把记忆换成检索」：不压缩历史，而是保留全部并动态加权。
  3. 式(1) 四步：算内积 → 除 √dk → softmax → 乘 V。输出与输入同长度。
  4. 注意力是按相关性加权的信息混合，不是「集中精神」。
  5. Q/K/V 是同一个 x 的三个投影，不是三个不同的东西。
  6. q·k 的方差是 dk，除以 √dk 后为 1。不除会饱和成 one-hot，梯度消失；除以 dk 又太扁，退化成平均。
