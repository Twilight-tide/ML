Chapter 8

位置、残差与前馈

没有位置编码，模型分不清「狗咬人」和「人咬狗」

约 1 周 需写代码 对应 W12

上一章结束时，你有了一个能算注意力的模块。但它有一个致命缺陷：它不知道谁在前谁在后。 把输入的顺序打乱，输出只是跟着打乱，内容一模一样。这一章要补上三个「看起来是细节、实际上是支柱」的东西： 位置编码、残差连接、层归一化。再加上前馈网络，一个解码器层就齐了。

8.1 注意力是置换等变的

先证明这件事，因为它解释了为什么必须有位置编码。

设 P 是一个置换矩阵（左乘它相当于把行重新排列）。那么：

Attention(PX) = softmax(PXW(PXW)T) PXV = softmax(PXWWTXTPT) PXV

因为 PTP = I，中间的 PTP 抵消了。 而 softmax 是逐行操作的，置换行只是置换输出行。最终：

Attention(PX) = P · Attention(X)

也就是说：把输入打乱，输出也只是跟着打乱，每个位置上的值完全不变。

要点

「狗咬人」和「人咬狗」的 token 集合完全相同，只是顺序不同。 纯注意力对这两句话的输出是一样的（只是排列不同）——它根本无法区分。 位置信息不是可选的补充，是语言模型的前提。

8.2 正弦位置编码

论文 §3.5 的做法是给每个位置算一个 d_model 维的向量，直接加到嵌入上：

PE(pos, 2i) = sin( pos / 100002i/dmodel )
PE(pos, 2i+1) = cos( pos / 100002i/dmodel ) pos 是位置，i 是维度索引

偶数维用 sin，奇数维用 cos，每一对 (2i, 2i+1) 共享同一个频率。 频率从 i=0 时的 1（波长 2π）一直降到 i=d/2 时的 1/10000（波长 20000π）。 高维变化极慢，低维变化极快，形成一组「不同刻度的尺子」。

维度 0,1
波长 2π
维度 2,3
波长 2π·1000.03
…
维度 62,63
波长 20000π

为什么这个设计好

关键性质是：任意固定位移 k 的位置编码，都可以由位移 0 的位置编码通过一个线性变换得到。

看一对 (2i, 2i+1)，记 ω = 1/100002i/d，那么：

[ sin((pos+k)ω) ] [ cos(kω) sin(kω) ] [ sin(pos·ω) ]
[ cos((pos+k)ω) ] = [ −sin(kω) cos(kω) ] [ cos(pos·ω) ]

右边那个 2×2 矩阵只和 k 有关，和 pos 无关。这正是三角函数的和角公式。

含义是：模型如果学会了「往前看 3 个位置」这个操作，那么它在位置 10 和位置 500 用的是同一个线性变换。 相对位置的信息被编码成了一个与绝对位置无关的旋转。

要点

论文选正弦编码的两个理由：

  1. 相对位置可表达。PE(pos+k) 是 PE(pos) 的线性函数，模型容易学会「看相对距离」。
  2. 可以外推到训练时没见过的长度。即使训练只用 64 长度，推理时算到 200 也能算出合法的编码。

但这两条都值得怀疑

第一个理由成立，但它不是唯一的实现方式。第二个理由在实践中很少真的奏效—— 模型在训练长度之外的表现通常会显著下降，不管用不用正弦编码。

后来的工作（包括 GPT 系列）大多改用可学习的位置嵌入：就是一个 (max_len, d_model) 的矩阵，当作参数训练。 它在训练范围内往往略好，代价是完全无法外推。

陷阱

不要因为论文写了「可以外推」就以为它能外推。 这个说法在 2017 年是一种设计期望，不是实验结论。论文自己也没有做长度外推的实验。 读论文时要注意区分「作者声称」和「作者证明」。

8.3 残差连接

第 4 章说过，梯度是连乘的，深了就会消失。残差是最简单的解法：

y = x + f(x) f 是子层（注意力或 FFN）

求导：

∂y/∂x = I + ∂f/∂x

那个 I 就是「高速公路」。即使 ∂f/∂x 小到 0，梯度也能原样传回去。 50 层连乘 0.1 会消失，但连乘 (1 + 0.1) 会爆炸——所以还需要 LayerNorm 来压住它。

残差还有一个解释：它让每一层只需要学「增量」，而不是「完整的表示」。 如果某一层没什么可学的，它可以把 f(x) 输出成 0，这一层就退化成恒等映射，不影响整体。 这让「加深」变成了一件安全的事。

陷阱

残差要求 x 和 f(x) 形状相同。 所以 d_model 在所有子层里必须保持一致，注意力输出和 FFN 输出都必须投影回 d_model。 这也是为什么 WO 和 W₂ 存在——它们不只是「混合信息」，还负责把维度对齐。

8.4 LayerNorm 与 BatchNorm 的分水岭

两者的公式长得几乎一样，区别只在「沿哪个方向算均值和方差」：

LayerNorm(x) = γ ⊙ (x − μ) / √(σ² + ε) + β

BatchNormLayerNorm
统计维度跨 batch（同一个特征，不同样本）跨特征（同一个样本，所有维度）
依赖 batch size是，batch 小就不稳否，单样本也能算

为什么 NLP 必须用 LN？三个理由，从弱到强：

  1. 序列长度不一，padding 会让 BN 的统计量失真。
  2. batch size 常常很小（受显存限制），BN 的均值方差估计噪声太大。
  3. 最根本的：BN 的统计量依赖「同一 batch 里的其他样本」，这让训练和推理的行为不一致， 而且在自回归生成时（一次只有一个样本）根本无法计算。
要点

LN 是对每个 token 独立做的：把这个 token 的 64 维向量拉出来，算均值方差，归一化。 它不关心 batch 里还有什么，也不关心序列有多长。这种「与上下文无关」的性质，正是自回归生成需要的。

8.5 Post-LN 还是 Pre-LN

残差和 LN 谁先谁后，有两种排法：

Post-LN：x ← LN(x + Sublayer(x))
Pre-LN：　x ← x + Sublayer(LN(x))

论文用的是 Post-LN（§3.1：the output of each sub-layer is LayerNorm(x + Sublayer(x))）。 这也是 src/model.py 里的写法。

两者的差别不大，但后果不小：

Post-LN（论文）Pre-LN（GPT-2 之后）
梯度要穿过 LN 才能回到残差，衰减快残差是纯恒等路径，梯度直达
训练稳定性差，必须配 warmup好，warmup 可以省
最终性能略好（调好的话）略差一点
用在哪原始 Transformer、BERTGPT-2/3、LLaMA

这就解释了论文 §5.3 那个奇怪的学习率曲线：为什么要先 warmup 再衰减？ 因为 Post-LN 在训练初期极不稳定，直接用大学习率会炸。先用小学习率「热身」，等参数进入稳定区域再放大。

要点

warmup 不是「玄学技巧」，它是 Post-LN 架构的补丁。 换成 Pre-LN，很多模型就不需要 warmup 了。理解这个因果关系，比记住「要 warmup」有用得多。

8.6 前馈网络：式(2)

每个解码器层的第二个子层是一个两层 MLP，对每个位置独立作用：

FFN(x) = max(0, xW1 + b1) W2 + b2 式(2)　中间维度 d_ff，通常 = 4 × d_model

「逐位置」意味着：位置 1 的 FFN 和位置 2 的 FFN 用的是同一组权重，但互不影响。 它不看上下文——上下文的信息已经在注意力子层里混合过了。

用代码说，它等价于两个 1×1 卷积：

(B,T,64)
→
Linear 64→232
→
ReLU
→
Linear 232→64
→
(B,T,64)

为什么中间要放大 4 倍？这是一个经验值，没有严格理论。直观的解释是： 注意力负责「在位置之间搬运信息」，FFN 负责「在每个位置上做非线性加工」。 加工需要更大的工作空间，所以先升维再降维。参数量上，FFN 通常占整个模型的一半以上。

本项目 d_ff=232 而不是 256，纯粹是为了凑 10 万参数（第 1 章算过）。 论文的 2048 = 4 × 512，比例是标准的 4 倍。

8.7 完整实现

class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000, dropout=0.0):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

        pe = torch.zeros(max_len, d_model)
        pos = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)

        # 10000^(2i/d) 在对数域算：exp((2i/d) * ln(10000))
        # 直接算 10000 ** (2i/d) 在 d 大时会溢出
        div = torch.exp(torch.arange(0, d_model, 2).float()
                        * (-math.log(10000.0) / d_model))

        pe[:, 0::2] = torch.sin(pos * div)
        pe[:, 1::2] = torch.cos(pos * div)

        # register_buffer：存进 state_dict 但不参与训练
        self.register_buffer("pe", pe.unsqueeze(0))

    def forward(self, x):
        return self.dropout(x + self.pe[:, :x.size(1)])

然后是解码器层，把注意力、FFN、残差、LN 拼起来：

class DecoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)
        self.ffn = PositionwiseFeedForward(d_model, d_ff, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        # 子层 1：掩蔽自注意力（Post-LN）
        a, attn = self.self_attn(x, mask)
        x = self.norm1(x + self.dropout1(a))

        # 子层 2：前馈（Post-LN）
        x = self.norm2(x + self.dropout2(self.ffn(x)))
        return x, attn

两个子层的结构完全对称：算 → dropout → 加残差 → 归一化。 这个模式会重复 N 次，论文里 N=6，本项目 N=2。

要点

到这里，一个解码器层的所有零件都齐了：多头注意力、FFN、两个 LN、两个残差、两个 dropout。 把它们按顺序摆好，就是论文图 1 右半边。下一章只需要再加三样东西：掩码、权重共享、输出层。

本章要点

  1. 注意力对置换是等变的：打乱输入，输出只是跟着打乱。没有位置编码，模型分不清语序。
  2. 正弦编码的关键性质：PE(pos+k) 是 PE(pos) 的线性函数，相对位置可被线性表达。
  3. 「可以外推到更长序列」是设计期望，不是实验结论。现代模型多用可学习位置嵌入。
  4. 残差提供梯度高速公路；它要求子层输出和输入同维度，这就是 WO 和 W₂ 的第二个作用。
  5. LN 沿特征维归一化，与 batch 和序列长度无关——这是自回归生成能工作的前提。
  6. Post-LN 不稳定，所以才需要 warmup。这是因果关系，不是两条独立的规则。
