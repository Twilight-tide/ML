Appendix C

从线性回归到梯度公式

把 ∇ = (2/n) Xᵀ(Xw − y) 一步一步推出来

约 2 小时 只需会求导 配合 2.6 节阅读

这个公式在整个项目里只出现一次，却是理解「训练」的起点。 它看起来像变魔术：一堆矩阵忽然变成了一个梯度。这一节把它拆开， 从「线性回归是什么」开始，用两种完全不同的方法各推一遍，最后给出几何解释。 两种方法都推完，你就不需要「记住」这个公式了。

这一节需要的前置

只有三样：平方、求和、一元求导。 矩阵求导的公式我会现推，不假设你背过。如果你会链式法则，就足够了。

C.1 线性回归要解决什么问题

手上有 n 个样本。每个样本有两个东西：

  • 一组特征 xi = (xi1, xi2, …, xid)，d 个数
  • 一个答案 yi，一个数

我们想找一个线性函数，把特征映射成答案：

ŷi = w1xi1 + w2xi2 + … + wdxid ŷ 读作「y hat」，表示模型的预测值

一组权重 w 就定义了一个模型。问题变成：哪一组 w 最好？

「最好」需要一个标准。最自然的标准是：预测值和真实值的差距越小越好。

ei = ŷi − yi = w · xi − yi 第 i 个样本的残差（residual）

C.2 为什么是「平方和」

直接把所有残差加起来行不行？不行，因为正负会抵消。

比如两个样本，一个误差 +10，一个误差 −10，加起来是 0——看起来完美，实际上错得离谱。

所以要消除符号。两种常见做法：取绝对值，或者取平方。选平方有三个理由：

  1. 可导。绝对值在 0 点不可导，平方处处可导。我们要对它求梯度，这一点是硬要求。
  2. 惩罚大误差。误差 2 的样本，平方后贡献 4；误差 10 的，贡献 100。模型会优先修大错。
  3. 有概率解释。如果假设噪声服从正态分布，最大化似然等价于最小化平方和。

于是损失函数定义为「平均平方误差」：

L(w) = (1/n) Σi=1n ( w · xi − yi )² 除以 n 是为了取平均，让 loss 和数据量无关

C.3 把所有样本写成矩阵

上面那个式子对每个样本写一遍，太啰嗦。把 n 个样本堆成矩阵，一次算完。 

       特征 1   特征 2   ...  特征 d
样本1  [ x_11    x_12    ...  x_1d ]        y_1
样本2  [ x_21    x_22    ...  x_2d ]        y_2
 ...   [  ...     ...    ...   ... ]        ...
样本n  [ x_n1    x_n2    ...  x_nd ]        y_n

        X 形状 (n, d)                      y 形状 (n,)

那么所有预测值可以一次算出来：

ŷ = Xw (n,d) 乘 (d,) 得到 (n,)，每一行是一个样本的预测

残差向量就是：

r = Xw − y 形状 (n,)，第 i 个分量是第 i 个样本的误差

而「平方和」在矩阵语言里是向量的内积：

‖r‖² = rTr = Σi ri² 一个向量的平方和，等于它和自己的内积

所以损失函数写成：

L(w) = (1/n) ( Xw − y )T( Xw − y ) 式(C-1)
要点

到这一步，问题已经完全清楚了：L 是一个关于 w 的函数，我们要找让它最小的 w。 梯度 ∇L 是一个和 w 同维的向量，第 k 个分量是 ∂L/∂wk。 算出这个向量，就是本节的全部任务。

C.4 方法一：逐个分量推（不需要任何矩阵公式）

这是最扎实的路径。它慢，但每一步你都能自己验证。如果你只有高数基础，走这条。

第 1 步：把 L 写成双重求和

把矩阵乘法展开成标量：

ŷi = Σj=1d Xij wj 第 i 行和 w 做内积

所以损失是：

L = (1/n) Σi=1n ( Σj=1d Xij wj − yi )²

为了少写字，记括号里那坨为 ri：

ri = Σj Xij wj − yi　　⟹　　L = (1/n) Σi ri²

第 2 步：对某一个 wk 求偏导

关键认知：w 有 d 个分量，我们一次只对其中一个求导。其他的当常数。

∂L/∂wk = (1/n) Σi ∂(ri²)/∂wk

对每一项用链式法则：外层是平方，内层是 ri。

∂(ri²)/∂wk = 2 ri · ∂ri/∂wk

第 3 步：算 ∂ri/∂wk

展开 ri：

ri = Xi1w1 + Xi2w2 + … + Xikwk + … + Xidwd − yi

对 wk 求偏导时，除了 Xikwk 这一项， 其他项都不含 wk，导数为 0。而 Xikwk 对 wk 的导数是 Xik。

∂ri/∂wk = Xik 只有第 k 个特征那一项活了下来

第 4 步：代回去

∂L/∂wk = (1/n) Σi 2 ri Xik = (2/n) Σi Xik ( Xw − y )i

注意最后一步把 ri 写回去了，因为 ri = (Xw − y)i。

第 5 步：认出这是矩阵乘法

现在看这个求和：

Σi Xik ( Xw − y )i

它是一个「固定 k，对 i 求和」的式子。回想矩阵乘法的定义：

(XTv)k = Σi (XT)ki vi = Σi Xik vi 转置之后，第 k 行第 i 列就是原来的第 i 行第 k 列

把 v 换成 (Xw − y)，正好对上。所以：

∂L/∂wk = (2/n) [ XT( Xw − y ) ]k

第 6 步：从分量回到整个向量

这个等式对每一个 k = 1, …, d 都成立。 「向量的每个分量都相等」就意味着「向量相等」。

∇L = (2/n) XT( Xw − y ) 式(C-2)　方法一推导完毕
动手

拿一张纸，把第 1 到第 5 步自己写一遍。中间不要看这里。 如果卡在「为什么只有 Xik 活下来」，就在纸上写 d=3 的展开式，用具体数字算一次。

C.5 方法二：矩阵求导（更快，但要两条规则）

方法一已经把结果推出来了。方法二的意义在于：以后遇到更复杂的损失函数，你不用再逐分量展开。 但那两条规则得先证明，不能直接拿来用。

第 1 步：把 L 展开成四项

用分配律展开（注意 Xw 和 y 都是列向量）：

(Xw − y)T(Xw − y) = (Xw)T(Xw) − (Xw)Ty − yT(Xw) + yTy

用转置的性质 (AB)T = BTAT 化简第一项：

(Xw)T(Xw) = wTXTXw

第 2 步：合并中间两项

关键观察：wTXTy 是一个标量（1×1 的矩阵）。

标量有一个显然但重要的性质：它等于自己的转置。

(wTXTy)T = yTXw

所以中间两项相等，合并成 −2wTXTy：

L = (1/n) [ wTXTXw − 2wTXTy + yTy ] 式(C-3)

第 3 步：准备两条求导规则

式子有三个部分，需要两条规则。先证明它们。

规则 A：∂(bTw)/∂w = b

展开成标量：bTw = Σi biwi。

对 wk 求偏导，只有 bkwk 那一项有贡献，导数是 bk。

∂/∂wk (Σi biwi) = bk　⟹　梯度 = b

规则 B：∂(wTAw)/∂w = 2Aw（当 A 对称）

展开：

wTAw = Σi Σj wi Aij wj

对 wk 求偏导。这个双重求和里，含 wk 的项有两类：

  • i = k 的那些项：Σj Akjwj，对 wk 求导得 (Aw)k
  • j = k 的那些项：Σi wiAik，对 wk 求导得 (ATw)k

（i = j = k 那一项被算了两次，但因为它对 wk 是二次的，导数正好是 2Akkwk，所以没错。）

∂/∂wk = (Aw)k + (ATw)k

如果 A 是对称矩阵（AT = A），两项相同：

∂(wTAw)/∂w = 2Aw
要点

这里有个容易忽略的点：XTX 一定是对称的。
因为 (XTX)T = XT(XT)T = XTX。
所以规则 B 可以直接用，不用管不对称的情况。

第 4 步：逐项求导

对照式(C-3)，令 A = XTX，b = XTy：

项形式导数
第一项wT(XTX)w2XTXw（规则 B）
第二项−2wT(XTy)−2XTy（规则 A）
第三项yTy0（不含 w）

第 5 步：合起来

∇L = (1/n) [ 2XTXw − 2XTy ] = (2/n) XT ( Xw − y )

和方法一的结果完全一致。

要点

两条路，一条逐分量（慢但透明），一条矩阵求导（快但需要规则）。 两条都走通，你才算真的会了。只走一条，容易在换个场景时卡住。

C.6 梯度为零意味着什么

令 ∇L = 0：

XT( Xw − y ) = 0

记残差 r = y − Xw（注意符号反过来了），条件变成：

XTr = 0

把它写成每个分量的形式：

(XTr)k = Σi Xik ri = 0　（对每个 k）

这个求和是什么？它是第 k 个特征那一列，和残差向量的内积。 内积为 0，意味着正交。

几何意义

最优解的残差，和 X 的每一列都垂直。

换个说法：Xw 能到达的所有可能，构成 X 的列空间（一个 d 维的子空间，藏在 n 维空间里）。 y 一般不在这个子空间里。我们要找子空间里离 y 最近的那个点。 而「最近」的几何条件正是：连线（残差）垂直于这个子空间。

所以最小二乘的代数条件和几何直觉是同一件事。

C.7 解出 w

从 XT(Xw − y) = 0 出发：

XTXw = XTy　　　（正规方程 normal equation）
w = (XTX)−1 XTy 前提：XTX 可逆，即 X 的列线性无关

这就是 2.6 节那段代码在做的事：

w_ls = np.linalg.solve(X.T @ X, X.T @ y)

用 solve 而不是 inv，是因为解线性方程组比求逆再乘更稳、更快。 数学上等价，数值上 solve 更好。

C.8 手算一个完整例子

两个样本，一个特征，所以 w 是一个数。

X = [[1],        y = [3,
     [2]]             5]        n = 2, d = 1

损失函数：

L(w) = (1/2) [ (1·w − 3)² + (2·w − 5)² ]

展开：

= (1/2) [ (w² − 6w + 9) + (4w² − 20w + 25) ]
= (1/2) [ 5w² − 26w + 34 ]
= 2.5w² − 13w + 17

求导并令其为 0：

dL/dw = 5w − 13 = 0　⟹　w = 13/5 = 2.6

用公式验证。先算两个量：

XTX = [1 2] · [[1],[2]] = 1² + 2² = 5
XTy = [1 2] · [3, 5] = 1·3 + 2·5 = 13

代入梯度公式：

∇ = (2/n) XT(Xw − y)
= (2/2) [ 5w − 13 ] = 5w − 13

和手算的导数一模一样。再解 5w − 13 = 0，得 w = 2.6，也一致。

动手

把这个例子改成 X = [[1],[2],[3]]、y = [2, 4, 6]， 自己算一遍。答案应该是 w = 2（因为数据完全在 y = 2x 上，残差为 0）。

C.9 那 2 和 n 到底起什么作用

很多人第一次看到 (2/n) 会问：为什么要带这两个常数？

  • 2 来自平方求导。d(x²)/dx = 2x，这个 2 一定会出现。
  • n 来自取平均。L 定义里除以 n，求导后保留。

它们不改变最优解的位置——因为常数因子乘在梯度上，让梯度为 0 的点还是那些点。

但在梯度下降里，它们会和学习率合并：

w ← w − η · (2/n)XT(Xw − y)

如果嫌 (2/n) 麻烦，可以把它吸收进 η：定义 η' = 2η/n，式子就变成 w ← w − η'XT(Xw − y)。 数学等价，只是学习率的含义变了。

C.10 和代码逐行对应

pred = X @ w_gd                      # ŷ = Xw
loss = ((pred - y) ** 2).mean()      # L = (1/n) Σ (ŷᵢ - yᵢ)²
grad = 2 * X.T @ (pred - y) / n      # ∇L = (2/n) Xᵀ(Xw - y)
w_gd -= lr * grad                    # w ← w - η∇L

四行代码，四个公式，一一对应。现在这四行对你来说不再是黑箱了。

C.11 带截距怎么办

前面的模型没有截距项。真实的线性回归通常是：

ŷi = w · xi + b

处理办法很巧妙：给 X 加一列全 1，把 b 当成 w 的最后一个分量。

原 X (n, 2)          →    X' (n, 3)
[[x11, x12]]              [[x11, x12, 1]]
[[x21, x22]]              [[x21, x22, 1]]
  ...                       ...
[[xn1, xn2]]              [[xn1, xn2, 1]]

w = [w1, w2]         →    w' = [w1, w2, b]

这样一来 X′w′ = w1x1 + w2x2 + b， 就和原来的式子完全一样了。

所以梯度公式一个字都不用改。这也是为什么代码里 X 的形状是 (n, d) 而不是 (n, d+1)—— 2.6 节的例子没加截距，如果你想加，就在 X 后面 np.hstack([X, np.ones((n,1))])。

C.12 小结

这条推导链的五个关节

  1. 模型：ŷ = Xw，把所有样本的预测写成一个矩阵乘法。
  2. 损失：L = (1/n)‖Xw − y‖²，平方是为了消除符号且处处可导。
  3. 求导：对每个 wk 单独求偏导，只有 Xikwk 那一项有贡献。
  4. 组装：ΣiXik(Xw−y)i 正是 XT(Xw−y) 的第 k 个分量。
  5. 几何：梯度为零 ⟺ 残差与 X 的每一列正交 ⟺ 预测点是列空间中离 y 最近的点。

练习

  1. 不看正文，用分量法把梯度推一遍。卡住的地方回去看 C.4 的对应步骤。
  2. 用矩阵求导法推一遍，写出每一步用了哪条规则。
  3. 手算 X=[[1],[2],[3]]、y=[2,4,6] 的例子，验证 w = 2。
  4. 如果损失改成 L = (1/n)Σ|ŷi − yi|（绝对值），梯度是什么？ 在 w 等于最优解时会出什么问题？ 绝对值在 0 点不可导，梯度会在最优点附近震荡。
  5. （进阶）如果给损失加上 L2 正则 L = (1/n)‖Xw−y‖² + λ‖w‖²，重新求梯度。 答案：(2/n)Xᵀ(Xw−y) + 2λw。这就是「权重衰减」。
  6. （思考）为什么说 XTX 可逆要求「X 的列线性无关」？ 如果两列完全一样会发生什么？ 可以从「有两个特征提供完全相同的信息」这个角度理解。
