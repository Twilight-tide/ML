## M5 规则评价与约束解码对照　2026-11-17

### 平仄表：从语料反推，不用拼音库

pip 装 pypinyin 在这个环境里卡住（pip 26.2.1 + Python 3.14 的老问题），
改用「从语料反推」：

对联规则是上仄下平，所以统计每个字在**上下联末字**的分布即可判定：
大量出现在下联末尾 → 平声；大量出现在上联末尾 → 仄声。

实测（74 万个末字，出现 >= 20 次的 3,012 字）：
```
可判定 2,909 字（1,305 平 / 1,604 仄），仅 4% 无法判定
24 个已知平仄的字全部判对（风花山天…判平，月水树地…判仄）
占比分布双峰：0.0-0.1 有 1,445 字，0.9-1.0 有 1,248 字，
            中间 0.3-0.7 只有 105 字 —— 形状本身证明规则真实存在
test 集上下联末字都可判：96.5%
```
产物 `data/tone_table.json`（42 KB，入库）。代码 `src/tone.py`。

### 四条规则评测（200 条测试样本，run2）

| 规则 | 参考答案 | 模型 | 差距 |
|---|---|---|---|
| 字数相等 | 100.0% | 98.0% | -2.0 |
| 无重字 | 83.5% | 46.5% | **-37.0** |
| 上仄下平 | 97.4% | **97.9%** | **+0.5** |

**平仄已超过参考答案**。参考答案 97.4% 同时在验证判据本身有效。
**唯一短板是重字**。

### 约束解码消融实验（同 200 条）

| 指标 | 普通贪心 | 禁止重字 | 变化 |
|---|---|---|---|
| 字数相等 | 98.0% | 97.5% | -0.5 |
| 无重字 | 46.5% | **100.0%** | +53.5 |
| 上仄下平 | 97.9% | 97.9% | 0 |

代价仅 0.5 个百分点，平仄零损失。

### 核心结论

三类规则的学习难度完全不同：
1. **局部可判**（末字平仄）→ 模型自己就学会了，甚至超过参考
2. **需要全局记忆**（整句不重字）→ 学不会（46.5%），但一条硬约束就能零成本解决
3. **长度约束**（字数相等）→ 学得很好（98%），因为答案由输入直接决定

这说明「期待模型学会规则」和「把规则写进解码过程」是两条不同的路，
后者对确定性规则更高效。这是本项目最有方法论价值的一条。

夺 吸 割 劫 匣 博 啄 塞 勒 嚼 …… **全部是入声字**。

普通话「入派三声」，入声字被分到一二三四声；一二声在普通话是平声，
但在格律里入声属仄。对联用传统音韵，不用普通话音系。

决定性检验（用两把尺子量同一批数据，看哪把量出的规则遵守率更高）：
```

  按语料表的判定   288 条，符合率 84.72%
  按 pypinyin 判定 290 条，符合率 11.72%   ← 接近系统性反向
```

结论：**语料反推表在对联任务上显著优于普通话拼音**。11.72% 远低于随机的 50%，
说明不是噪声，而是音系不匹配。
