# 安装方式（在项目根目录、已激活 .venv 的终端里执行）：
#     pip install -r requirements.txt
#
# -----------------------------------------------------------------------------
# 【为什么要用 --extra-index-url 指向 PyTorch 官方源】
#
# PyPI 上的 torch 是 CPU-only 构建（内部只有 torch_cpu.dll，没有任何 CUDA 二进制）。
# 如果直接 pip install torch，会装上 CPU 版：
#     - 不会报任何错
#     - 但 torch.cuda.is_available() 返回 False，显卡完全用不上
#
# CUDA 版只在 PyTorch 官方索引上，且版本号带本地标识 +cu128。
# 因此必须显式指定索引，并锁死带 +cu128 后缀的版本号。
#
# 【为什么是 cu128 而不是更新的版本】
#
# 本机显卡驱动为 573.24，只支持到 CUDA 12.8。各版本驱动要求（Windows）：
#     cu126  需要 >= 560.76  但 不支持 Blackwell(sm_120)，装了也用不了
#     cu128  需要 >= 572.61  ✓ 本机满足，且是首个支持 sm_120 的版本
#     cu129  需要 >= 576.02  ✗ 驱动不够
#     cu130  需要 >= 580     ✗ 驱动不够
# 所以 cu128 是本机在当前驱动下唯一可用的选择。
# -----------------------------------------------------------------------------

# 国内镜像（清华源，下载快）。若在国外或该镜像不可用，可删除本行。
