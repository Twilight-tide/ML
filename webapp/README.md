# webapp · 实时预测分布可视化

一个零依赖的本地网页应用：给定任意文本，展示 10 万参数模型对「下一个字符」的预测分布。

## 运行

在项目根目录、已激活虚拟环境的终端里：

```powershell
.\.venv\Scripts\Activate.ps1
python webapp/server.py
```

浏览器打开 <http://127.0.0.1:7860>。`Ctrl+C` 结束。

依赖只有 `torch` 和 Python 标准库，不需要 Flask / Gradio / 任何前端框架。

## 它做什么

后端只做一次前向：把输入文本喂给 `results/model.pt`，取最后一个位置的 `logits`，
连同整段文本的困惑度一起返回。前端负责把 logits 按温度做 softmax，画成条形图。

**温度是在前端算的**，所以拖动滑块零延迟，不会重新请求。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 页面 |
| GET | `/api/meta` | 参数量、设备、词表大小 |
| POST | `/api/predict` | 请求体 `{"text": "..."}`，返回 top-20 logits、ppl、熵 |

## 几个可以观察的现象

| 输入 | 现象 |
|---|---|
| `def ` | 分布很尖，最可能是 `_` |
| `def _get_` | top1 仍是 `_`，但在猜函数名的下一个音节 |
| `import os` + 换行 | **困惑度 5.18（高）但熵 0.83（低）**——不知道前文，但确定要缩进 |
| 任意中文 | 全部 out_of_vocab，词表只有 96 个 ASCII 字符 |

第三种是核心现象：**同一时刻，整体判断差、局部判断准**，这是小模型「学到语法、没学到语义」的直接证据。
